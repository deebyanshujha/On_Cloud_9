Hackathon build order

Build top-to-bottom, left-to-right in the diagram. Get Steps 1–5 working with ONE source (ClinicalTrials.gov) before adding bioRxiv. The comparison engine (Step 5) is your core IP — prioritize it over more sources or UI polish.

Cut-list if short on time

Drop Semantic Scholar first, then the graph visualization, then bioRxiv/Claude extraction. Never cut the comparison engine or the validation step — that's what proves the system actually works.

Key APIs (all free)

ClinicalTrials.gov v2, bioRxiv/medRxiv, Open Targets GraphQL, DrugCentral/RxNorm, Semantic Scholar, Anthropic API for text extraction.

Demo moment

Show a live-detected signal, click through to its source trial/paper, then show the system independently rediscovering a known case (metformin → cancer) to prove it's not just showing noise.
